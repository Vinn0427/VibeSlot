## 1. 体验目标

| # | 目标 | 衡量方式 |
|---|---|---|
| X1 | **3 秒内开始转**：首页点一次就到老虎机，老虎机页不需要任何准备就能转 | 首页 → 第一次转动只需 2 次点击（选场景 + 转一下） |
| X2 | **转动有手感**：期待感来自“依次停止”的节奏和停下那一刻的落定感 | 内部试玩：10 个人里至少 7 人主动转第二次 |
| X3 | **结果一眼看懂**：结果句子是页面上最大的文字，几个人围着一台手机也能看清 | 一臂距离可读；结果句 ≥ 22px |
| X4 | **大拇指就能玩**：所有高频操作都在屏幕下半部分 | 主按钮、锁定按钮、结果卡片按钮都在单手拇指热区 |
| X5 | **不像赌场**：好玩、年轻，但不出现金币、777、筹码、红金配色 | 视觉评审 |

## 2. 信息架构

### 2.1 页面与地址【建议，TECH_DESIGN 可调整路由实现】

| 页面 | 地址 | 说明 |
|---|---|---|
| 首页 | `/` | 场景入口、我的老虎机、反馈 |
| 老虎机页 | `/play/{templateId}` | 预设用固定 ID（`cook` / `date` / `party` / `mix` / `couple`），自定义模板用生成的 ID |
| 老虎机页（临时模式） | `/play/shared` | 从导入预览页“直接转一下”进入，不保存；刷新后回到导入预览页（数据仍在短链中） |
| 模板编辑器 | `/edit/new`、`/edit/{templateId}`、`/edit/copy/{templateId}` | 新建 / 编辑 / 复制 |
| 导入预览页 | `/s/{shortId}`、`/import#t=...` | 短链接 / 长链接兜底 |
| 错误页 | 由各页面内联显示 | 不单独设地址 |

页面内的**底部弹层**（不改变地址）：设置面板、列展开面板、分享面板（兜底）、确认框。

## 3. 全局布局与组件

### 3.1 布局基准

| 项 | 规格 |
|---|---|
| 设计基准 | 375 × 667（iPhone SE / 8），兼容 320 宽到 430 宽 |
| 页面左右边距 | 16px |
| 桌面端 | 内容区居中，最大宽度 480px；两侧为米白底，可以放少量大尺寸贴纸装饰；不做多栏或仪表盘式布局 |
| 安全区 | 顶部和底部固定栏要加上 `safe-area-inset` |
| 栅格间距 | 4 的倍数：4 / 8 / 12 / 16 / 24 / 32 |
| 最小点击区域 | 44 × 44px【PRD 非功能需求】 |

### 3.2 字号层级【建议，与 skill `visual-system.md` §5 一致，真机上微调】

| 用途 | 字号 / 字重 |
|---|---|
| 结果句子（决策类） | 22px / 800 |
| 结果句子（游戏类，需要围观） | 24px / 800 |
| 滚轮中心项（3 列） | 20px / 800 |
| 滚轮中心项（4 列） | 16px / 800 |
| 滚轮上下项 | 中心项字号 × 0.8，透明度 35% |
| 页面标题 | 18–22px / 800 |
| 主按钮 | 18px / 800 |
| 正文 / 次按钮 | 16px / 600 |
| 辅助文字 | 13px / 400，**不低于 12px** |

字体使用系统中文字体栈（见 skill），不下载中文网络字体；品牌字标用 SVG。

### 3.3 通用组件

| 组件 | 规格 |
|---|---|
| 顶部栏 | 高 48px；左：返回；中：标题（超长截断）；右：设置图标（仅老虎机页） |
| 主按钮 | 高 56px，圆角胶囊，全宽减去 32px 边距；**玩具按压**：按下时向阴影方向位移约 3px、硬阴影缩短到约 1px，80–120ms，松开复位 |
| 次按钮 | 高 44px，米白底 + 粗描边；按压效果同主按钮 |
| 卡片 / 弹层 / 机身 | 统一使用粗黑描边 + 零模糊的硬偏移阴影（参数见 skill），不使用毛玻璃、渐变、发光 |
| 底部弹层 | 从底部滑出，圆角 20px，最高 85% 屏高，内容可滚动；点遮罩、下滑、点“完成”都能关闭 |
| Toast | 屏幕上方、顶部栏下 8px，最长 2 行，显示 2 秒；同一时间只显示一条，新的替换旧的 |
| 确认框 | 居中对话框，标题 + 一句说明 + [取消] [确认]；危险操作的确认按钮用警示色 |
| 首次须知 | 居中卡片，场景图标 + 须知文案 + [知道了]；点遮罩不关闭（确保看到） |
| 引导气泡 | 指向某个元素的小气泡，点任意位置关闭 |

### 4.3 规则

- 预设卡片的顺序固定：做菜（大卡）→ 约会 → 聚会 → 调酒 → 情侣（PRD §4）【已确认：大卡固定为“今天做什么菜”】。
- 卡片文案使用 CONTENT_DESIGN §2.1，不得自行改写。
- **整张卡片是一个可点击的链接**；箭头标记只是装饰，不单独获得焦点。
- 卡片按下时使用玩具按压效果（§3.3），不能推动相邻卡片。
- “我的老虎机”按最近使用时间倒序；每项显示名称 + 列名摘要（“主食 × 饮品”），超长截断。
- **空状态**：没有自定义模板时，只显示虚线框“＋ 新建老虎机”和一行说明“把你自己的清单做成老虎机”。
- 自定义模板数量达到 50 个时，“新建老虎机”变灰，点击后 toast：“最多 50 个，先删掉一些吧”。
- 首页没有设置入口、没有登录入口；首页可以纵向滚动，不要求一屏放下全部内容。
- **320px 小屏**：隐藏品牌区的小老虎机插画和贴纸，缩小卡片插画；卡片标题必须完整显示。
- 首页允许同时出现 5 个场景色，但每张卡片内的辅助色不超过 2 种（skill `visual-system.md` §3）。

## 5. 老虎机页（核心）

### 5.1 线框（3 列，决策类，已出结果）

视觉参考：skill 中的 `02-cook.png`（做菜）、`03-couple.png`（情侣）、`04-party-settings.png`（聚会 + 设置面板）。这些是概念图，以下几点**以本节为准**：
- **不做拉杆**：主操作永远是底部主按钮。
- **滚轮里只显示文字**：不给选项配食物或手势图标（候选项只有 `label`）。
- 机身旁的贴纸插画最多 1–2 个，320px 小屏上先隐藏。
- “还剩 N 次”只在设置了次数上限时显示；“第 N 轮”只在游戏类场景显示。

```

│ ‹        今天做什么菜       ⚙ │  ← 顶部栏 48
```

### 5.2 区域说明

| 区域 | 内容 | 显示条件 |
|---|---|---|
| 顶部栏 | 返回、模板名称、设置 | 始终 |
| 临时模式横幅 | “这是朋友分享的老虎机” + [保存] | 仅临时模式，位于顶部栏下方，高 40 |
| 控制行 | 尺度分段选择器、可选列开关、内容类型入口（见 5.3） | 模板有相应能力时 |
| 状态行 | 决策类：“还剩 N 次” / “命运已定”；游戏类：“第 N 轮” | 决策类设置了次数上限时；游戏类始终显示 |
| 机身 | **一个**场景色机身，包住全部列名、滚轮窗口和锁定按钮；外框粗描边 + 硬阴影，各滚轮共用一条基线 | 始终 |
| 结果卡片 | 结果标签、结果句子、提示、卡片按钮 | `result` / `accepted` |
| 底部固定栏 | 主按钮 | 始终 |

**为什么把“就它了”放在卡片里，而不是底部栏**：主按钮（转动类操作）永远在同一位置，用户连续转的时候拇指不用移动；“接受结果”跟着结果出现，语义上也更自然。

### 5.3 控制行

控制行位于状态行上方，高 40px，水平排列，不需要时整行不显示。

| 控件 | 模板 | 形式 | 规则 |
|---|---|---|---|
| 尺度选择 | `couple` | 3 段分段选择器：温和 / 心动 / 升温，选中段用对应温度色（浅粉 → 玫红 → 深玫红） | PRD F09；转动中不可用 |
| 可选列开关 | `mix`（“＋再加一种”）、`couple`（“＋加点规则”） | 胶囊开关，开启时为实心并显示“✓” | PRD F10；转动中不可用 |
| 内容类型入口 | `party` | 胶囊按钮“内容 3/4 类”，点击打开设置面板并滚动到“内容类型” | 让用户知道可以整组关掉某类内容 |

### 5.4 滚轮

| 项 | 规格 |
|---|---|
| 窗口 | 显示 3 行：上一项、中心项、下一项；每行高 56px，窗口高 168px；米白底，嵌在场景色机身内 |
| 内容 | **只显示 `label` 文字**，不显示图标或插画 |
| 中心项 | 字号最大、颜色最深，左右有指示箭头或高亮条，表示“这是结果” |
| 上下两项 | 缩小、变淡，上下边缘做渐隐遮罩，营造圆柱滚动感 |
| 列宽 | 等分：(机身内宽 − 列间距 8 × (N−1)) / N。375px 宽、机身内边距 12px 时，3 列约 98px，4 列约 72px；320px 宽时 4 列约 58px（中心项字号 16px 可显示约 3 字，其余省略） |
| 超长文字 | 单行，超出部分省略号（PRD E12）；结果卡片中完整显示 |
| 2 列 | 列宽上限 160px，整体居中，避免两列过宽显得空 |
| 新开启的可选列 | 显示“?”占位，虚线边框，直到下一次转动（PRD F10-4） |
| 被排除的当前值 | 中心项变为灰色 + 删除线（PRD F08-9） |
| 点击滚轮窗口 | 打开该列的展开面板（转动中无效） |

### 5.5 锁定

| 项 | 规格 |
|---|---|
| 位置 | 每列滚轮下方，与列等宽，高 44px |
| 未锁定 | 浅色底（米白或场景辅助色）+ 描边 + 硬阴影，打开的锁形图标 +“锁定” |
| 已锁定 | **深色底（墨黑）+ 米白文字**，闭合的锁形图标 +“已锁”，按钮处于“按下”状态（无阴影）；对应滚轮窗口描边加粗，并在右上角显示小锁角标。机身已是场景色，所以已锁定**不用场景色**区分，避免和机身混在一起；也不用灰色，避免被误认为禁用 |
| 4 列时 | 按钮文字可只保留图标 + “锁”，但无障碍标签保持完整（“锁定主料 / 已锁定主料”） |
| 切换动效 | 图标做一次 120ms 的“咔嗒”缩放（1 → 0.85 → 1）；滚轮窗口边框颜色过渡 150ms |
| 第一次转动前 | 按钮显示为禁用样式（透明度 40%），不可点击 |
| 转动中 | 全部禁用；已锁定的列保持锁定样式，滚轮完全静止 |
| 自动解锁（PRD F04-6/7） | 按钮恢复为未锁定，同时 toast：“『{列名}』已解锁” |
| 全部锁定（PRD E01） | 主按钮禁用，主按钮上方显示一行提示：“全都锁住了，解锁一列再转” |
| 首次引导 | 每台设备第一次出结果时，在锁定按钮上方显示引导气泡：“喜欢哪列就锁住它，再转其他的”。只显示 1 次（需同步到 PRD F17） |

### 5.6 状态与按钮行为

状态定义见 PRD F02。

**决策类（`cook` / `date` / `mix` / 自定义）**

| 状态 | 主按钮（底部栏） | 卡片按钮 | 锁定 | 点滚轮 | 控制行 / 设置 |
|---|---|---|---|---|---|
| `idle` | **转一下** | 无卡片 | 禁用 | 打开展开面板 | 可用 |
| `spinning` | 显示“转动中…”，禁用（P1 急停时为“停！”） | 无卡片 | 禁用 | 无效 | 禁用 |
| `result` | **再转一次**（次数用完时为“命运已定”，禁用） | **✓ 就它了** | 可用 | 打开展开面板 | 可用 |
| `accepted` | **重新开始** | **分享结果**（卡片显示“已决定”样式） | 可用；操作后回到 `result` | 打开展开面板 | 可用 |

**游戏类（`party` / `couple`）**

| 状态 | 主按钮（底部栏） | 卡片按钮 | 锁定 | 点滚轮 | 控制行 / 设置 |
|---|---|---|---|---|---|
| `idle` | **转一下** | 无卡片 | 禁用 | 打开展开面板 | 可用 |
| `spinning` | “转动中…”，禁用 | 无卡片 | 禁用 | 无效 | 禁用 |
| `result` | **换一个** | **✓ 完成** + 分享图标 | 可用 | 打开展开面板 | 可用 |
| `accepted` | **下一轮** | 分享图标（卡片显示“已完成”样式） | 可用 | 打开展开面板 | 可用 |

**主按钮在转动中的处理**：文字变为“转动中…”，按钮颜色变浅，但**位置和尺寸不变**，避免页面跳动。

### 5.7 重转逻辑（交互层面）

| 情形 | 行为 |
|---|---|
| 再转一次 / 换一个 / 下一轮 | 只有未锁定的列滚动；锁定的列完全静止 |
| 次数上限（决策类） | 第一次转动不计次。剩余 ≤ 1 时，状态行文字变为强调色；用完后主按钮显示“命运已定”并禁用，卡片的“就它了”按钮放大、跳动一次（scale 1 → 1.06 → 1） |
| 连续转 8 次未接受（决策类） | toast：“转了好多次啦，试试锁定喜欢的列？”（每次进入页面最多 1 次） |
| 重新开始 | 结果卡片淡出，所有锁定解除，滚轮停在当前位置（不再随机），回到 `idle` |
| 下一轮 | 卡片淡出 → 转动；轮数在**点击“完成”时** +1，数字做一次弹跳 |

### 5.8 结果卡片

| 元素 | 规格 |
|---|---|
| 结果标签 | 第一行，13px，用“×”连接；被排除的项显示删除线 |
| 结果句子 | 主体，字号见 §3.2，墨黑文字；句子中来自结果的部分用场景色的“马克笔”底色高亮（文字仍为墨黑，保证对比度） |
| 卡片材质 | 米白“纸票”底 + 粗描边 + 硬阴影 |
| 提示行 | `cook`：“AI 推荐菜谱即将上线”；有 `note` 的模板显示 `note`。13px，灰色；两者都没有时不显示 |

## 6. 转动动画与反馈

### 6.1 节奏参数【建议，开发后在真机上调参】

设参与转动的列从左到右为第 0、1、…、k 列（锁定的列不计入）。

| 阶段 | 参数 |
|---|---|
| 按下主按钮 | 玩具按压：位移约 3px + 硬阴影收缩，80–120ms |
| 加速 | 0 → 最高速，150ms，ease-in |
| 最高速 | 约每秒滚过 20–25 项；文字可以加轻微纵向模糊（用透明度或预渲染实现，避免实时 `filter: blur` 掉帧） |
| 第 i 列开始减速 | 停止时刻 \(T_i = 1100 + 300 \times i\) ms（从点击算起） |
| 减速 | 最后约 600ms，ease-out（推荐 cubic-bezier(0.15, 0.85, 0.3, 1)） |
| 落定 | 越过目标 6–8px 后回弹，120ms |
| 每列停止反馈 | 中心项缩放 1 → 1.08 → 1（140ms）；滚轮窗口边框闪亮一次 |
| 最后一列停止后 | 100ms 后结果卡片出现：上移 16px + 淡入，220ms |

总时长示例：3 列全部转动，最后一列在 1.7s 停止，加回弹约 1.82s；4 列约 2.12s；均满足 PRD 的 ≤ 2.5s。

### 6.2 实现约束（交给 TECH_DESIGN 细化）

- 只用 `transform: translateY` 和 `opacity` 做动画，保证 60fps。
- **结果在点击时就已确定**（PRD R02），动画是“把预先排好的一串项滚到目标项”。
- 每列滚动条带：前面随机填充若干项（可重复，但相邻不重复），最后一项是目标结果；条带长度由速度和时长决定。
- 预留事件：每列开始滚动、每列停止、全部停止、确定结果，供 V0.2 接入音效（PRD F18）。
- 页面切到后台再回来：直接显示最终结果（PRD E03）。

### 6.3 庆祝反馈

| 触发 | 反馈 |
|---|---|
| 就它了（决策类） | 撒彩纸：约 40 片，场景主色 + 2 种辅助色，从卡片位置向上喷出后落下，1.2s；卡片盖上印章 |
| 完成（游戏类） | 轻量版：约 20 片彩纸，0.8s；轮数弹跳；卡片盖上印章 |
| 命运已定 | 没有彩纸；“就它了”按钮跳动一次 |

彩纸**不得**使用金币、筹码、星星“777”等博彩元素，只用圆点、彩条、小方块。

### 6.4 减少动态效果（`prefers-reduced-motion`）

- 不做滚动：各列的文字依次淡出 / 淡入切换为结果，第 i 列在 \(300 + 100 \times i\) ms 完成，总时长 ≤ 0.8s。
- 没有回弹、缩放、彩纸、印章动画；印章直接显示。

- 老虎机页只用一种场景主色作为机身，辅助色最多 2 种；结果卡片是米白“纸票”。
- 全局禁用：渐变、毛玻璃、发光、金属质感；大面积红 + 金；金币、筹码、“777”、樱桃、BAR、扑克花色；拉杆不作为必需元素。
